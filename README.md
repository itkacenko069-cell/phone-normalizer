\## Призначення

Консольна програма мовою C#, яка приводить українські

телефонні номери до формату +380 XX XXX XX XX.



\## Можливості

\- Введення номера з початковим 0 або +380.

\- Видалення пробілів, дужок і дефісів.

\- Перевірка довжини та відхилення сторонніх символів.

\- Повторне введення номерів.

\- Команда exit для завершення.



\## Вимоги

.NET SDK 10.0.

Для роботи у Visual Studio потрібна підтримка C#.



\## Запуск

Відкрити PhoneNormalizer/PhoneNormalizer.slnx

у Visual Studio та натиснути Ctrl + F5.



Або виконати з кореневої папки репозиторію:

```shell

dotnet build PhoneNormalizer/PhoneNormalizer.csproj

dotnet run --project PhoneNormalizer/PhoneNormalizer.csproj

```



\## Приклад

Введення: (067)123-45-67

Результат: +380 67 123 45 67



Некоректні дані викликають повідомлення про помилку.

Контрольні приклади наведено у TESTS.md.

Префікси 380 без плюса та 00380 поки не підтримуються.

# Нормалізатор телефонних номерів

Консольна програма мовою C# для нормалізації українських телефонних номерів.

Автор: Ткаченко Іван Сергійович, група ПЗ2511.
Варіант 13.

## Можливості

- Підтримка форматів 0XXXXXXXXX, +380XXXXXXXXX, 380XXXXXXXXX та 00380XXXXXXXXX.
- Видалення пробілів, круглих дужок і дефісів.
- Перевірка довжини номера та наявності лише цифр після обробки префікса.
- Перевірка коду за дозволеним у програмі переліком: 50, 63, 66, 67, 68, 73, 93, 95, 96, 97, 98, 99.
- Виведення у форматі +380 XX XXX XX XX.
- Повторне введення номерів до команди exit.

## Приклади

0671234567 → +380 67 123 45 67
+380 (67) 123-45-67 → +380 67 123 45 67
380671234567 → +380 67 123 45 67
00380671234567 → +380 67 123 45 67
0121234567 → повідомлення про помилку
abc → повідомлення про помилку
